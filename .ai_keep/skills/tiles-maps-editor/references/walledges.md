# walledges.md — 墙边（建筑物外圈）怎么认、怎么换

这份文档记录一个**踩过的巨大坑**：我把建筑墙当"纯色砖纹贴图"程序化生成，
做出来是满地瓷砖的浴缸 —— 因为我**根本没认出来什么是墙边**。

---

## 一、墙边是什么

一栋楼 = **楼面（室内地面）** + **外圈一圈墙边**。

在延城一中（43×56，L1/L2/L3 三层）的实测：

| 位置 | gid | 是什么 |
|---|---|---|
| 包围盒**边界那一圈** | `13024` | **墙边**（左右两列 + 上下两行） |
| 内部那些格 | `13021` | **楼面**（室内地面） |
| 门/黑板 | `13027` | 门洞、黑板 |

看原始数据（教师办公室 x1..6 y21..27，L2）：

```
 y=21: 13024 13024 13024 13024 13024 13024   ← 上边（墙边）
 y=22: 13024 13021 13021 13021 13021 13024   ← 左墙边 | 楼面 | 右墙边
 y=23: 13024 13021 13021 13021 13021 13024
 y=24: 13024 13021 13021 13021 13021 13021
 y=25: 13024 13021 13021 13021 13021 13024
 y=26: 13024 13021 13021 13021 13021 13024
 y=27: 13024 13024 13024 13024 13024 13024   ← 下边（墙边）
```

**关键**：墙边**不是某个固定 gid**，而是「楼体外圈」这个**几何位置**。
判据 = 楼体格聚成连通块 → 取包围盒 → 边界那一圈。

> ⚠️ 改 gid 前一定先画红线看（见下节）。5 秒能避免一小时的错。

## 二、画红线看墙边（必做）

```sh
PY="C:/Users/viaco/.workbuddy-ai/binaries/python/versions/3.13.12/python.exe"
"$PY" workbuddy-ai/skills/tiles-maps-editor/scripts/mark_edges.py \
      <地图集>/maps/<name>.json --prefix 延城一中
```

产出三样：

| 文件 | 用途 |
|---|---|
| `<前缀>_轮廓红线.png` | 整图，每栋楼一个红框 —— 看有几栋楼、每栋多大 |
| `<前缀>_墙边高亮.png` | **墙边格红色覆盖**（半透明红 + 红描边）—— 确认墙边圈对了没 |
| `<前缀>_墙边_NN_x.._y..png` | 每栋楼 2~4 倍放大 —— 看单栋的边角 |

参数：
- `--layer N` 看第几层（延城一中楼体在 **L2**，默认 2）
- `--min-size N` 连通块最小格数（默认 10）
- `--structure g1,g2,...` 自定义"算楼体"的 gid 集合
- `--out 目录` 输出目录（默认 `../../../../.aispace/workbuddy-ai/cognition`）

## 三、图集里的立面家族

要换墙的贴图时，**图集里本来就有成套立面素材**，不用自己画。

### teal 青蓝家族（目标图用的就是这个）

位置：**col 77..81, row 61+**

| col | 角色 |
|---|---|
| 77 | **墙边立柱**（竖直青色发光条）← 就是"墙边"本体 |
| 78 | 带框砖墙（楼面边缘） |
| 79 | 砖墙（主体） |
| 80 | 墙角 |
| 81 | 窗墙 |

行节奏：亮层 / 暗层**每 2 行交替**（r61 亮、r63 暗、r65 亮…）。

### 砖墙家族

位置：**col 63..66**，每 3 行一个色系：

| row | 色系 |
|---|---|
| 73..75 | 米白 (186,148,122) |
| 76..78 | **橙砖** (176,110,52) ← 教学楼原来用的 |
| 79..81 | 灰绿 (108,97,84) |
| 82..84 | 红棕 (102,69,68) |

家族内列角色：c63 圆角 / c64 横砖 / c65 竖柱 / c66 边框。

### 自动扫描所有家族

```sh
"$PY" workbuddy-ai/skills/tiles-maps-editor/scripts/facades.py <图集.png> \
      --sheet /tmp/facades.png --json /tmp/facades.json
```

**判据是空间结构**（矩形块 + 纵向重复节奏 + 密度），**不是色系**。
理由：同一套立面里含大量明暗/冷暖变体（受光面/背光面/描边/窗玻璃），
实测青蓝家族里 teal 只占 24%，用色系过滤会全军覆没。

## 四、换墙的映射表

| 原来 | 换成 | 说明 |
|---|---|---|
| `13024`（墙边外圈） | teal `c77` 立柱（亮/暗层交替） | 墙边本体 |
| `13021`（楼面） | teal `c79` 砖墙 | 楼面 |
| `13027`（门/黑板） | 保留 | 门洞别动 |
| `7765/7766/7767/8005/8007`（木栅栏） | 深石板 | 走廊栏 |

**gid = tile index + 1**（本项目 `firstgid = 1`）。
用错会整体错位一格 —— 渲染出来是**黑色墙面**。

## 五、怎么判断换对了

改完必须**渲染 + 亲眼看**（铁律 #0）：

```sh
"$PY" workbuddy-ai/skills/cognitive-tiles-maps/scripts/inspect_map.py <地图.json>
"$PY" workbuddy-ai/skills/tiles-maps-editor/scripts/mark_edges.py <地图.json>
```

看墙边高亮图：
- 红色圈住的是**外圈**，不是整个楼体 ✓
- 楼面（内部）保持原样，家具还在上面 ✓
- 墙角（左上/右上/左下/右下）不出错位 ✓
