# 赦夜人冥夜走廊-第二季 · 技能参考列表

> 用途：① 写地图事件脚本时给 NPC/玩家挂载技能；② 给「暗核开箱 → AI 判定获得什么技能」提供**可抽取的技能池**（见 `野怪击杀奖励.事件.md`）。
> 每个技能的 JSON 都是**插件原生字段**，可直接当 `skillMeta[<技能名去括号小写>]` 的值使用。

---

## 1. 字段规范（插件 `SkillSlot` / `skillMeta` 真源：`entry.ts` `buildSkills`）

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| `name` | string | ✅ | 技能名。**最长 12 字**（`cleanSkillName(p).slice(0,12)`），超了会被截断；括号内容会被剥掉 |
| `power` | number | ✅ | 威力。`atk`=伤害值；`heal`=治疗量（实际取 `max(power, cost*2)`）；`buff`=0 |
| `cost` | number | ✅ | MP 消耗。AI 托管释放会扣蓝；玩家 HUD 释放**不扣蓝只进 CD** |
| `cd` | number | ✅ | 冷却，**单位 tick**（1 tick = 100ms，`TICK_MS=100`）。`cd=40` → 4 秒 |
| `cdLeft` | number | ✅ | 运行时剩余冷却，配置里恒写 `0` |
| `type` | `"atk"\|"heal"\|"buff"` | ✅ | 决定特效环：atal→斩波/火球，heal→治疗环，buff→护盾环 |
| `range` | `"melee"\|"ranged"` | ✅ | `melee`=弧形斩波；`ranged`=火球轨迹。**只在 `type=atk` 时生效** |
| `lv` | number | ✅ | 等级，来自参数卡字符串里的 `lvN`（如 `"湮源之力（lv1，失控）"`） |
| `buff_type` | string | ✅ | 仅 `type=buff` 有意义。取值：`Defense` / `Attack` / `Sustained_Damage` / `Stunning` / `Invincible` / `Accelerate` |
| `effects_type` | string | ✅ | 属性特效（决定颜色 + 26×26 图标）。见下表 |
| `perm_Life` | number | ⬜ | 技能永久加成·生命（叠进 `满血 = 100 + lv*10 + ...`） |
| `perm_Blue` | number | ⬜ | 永久加成·蓝量 |
| `perm_Attack` | number | ⬜ | 永久加成·攻击 |
| `perm_Defense` | number | ⬜ | 永久加成·防御 |

### `effects_type` 合法取值

| 值 | 图标 | 值 | 图标 |
|---|---|---|---|
| `""` | 无（默认） | `dark` | necromancy/agony |
| `normal` | sure_blade | `poison` | poison/alistairs_intoxication |
| `fire` | fire/fireball | `bleed` | necromancy/bolt_of_draining |
| `water` | ice/freeze | `buff_dmg` | 无图标（纯色环） |
| `thunder` | air/lightning_bolt | `buff_defense` | 无图标 |
| `wind` | air/tornado | `buff_dmg_bonus_fire` | 无图标 |
| `earth` / `metal` | earth/iron_shot | `buff_dmg_bonus_water` / `_thunder` / `_wind` / `_earth` / `_metal` / `_wood` / `_light` / `_dark` | 无图标 |
| `wood` | poison/poison_arrow | | |
| `light` | restoration/minor_heal | | |

### 数值口径（本剧配平基准）

- 玩家 lv1：`hp=150`、`mp=30`、`atk = 10 + lv*10 = 20`
- 玩家技能伤害 = **`power` 平推**（最多命中 3 个 4m 内敌人）；AI 托管释放 = `power + atk*0.5`
- 治疗量 = `max(power, cost*2)`
- 技能射程固定 `SKILL_RANGE_M = 4`（米），`range` 只影响特效表现
- 所以：**低阶技能 `cost` 别超过 20**（陈彦初始只有 30 蓝），`cd` 30~60 是常规战斗节奏

## 6. 暗核开箱抽取池（供 AI 判定「获得什么技能」）

| 湮物等级 | 可抽池 | 权重建议 |
|---------|--------|---------|
| 超一型 | B1-B5 | 均分，各 20% |
| 畸口（普通） | A4-A8 + B1-B5 | A 组 40% / B 组 60% |
| 畸口（精英） | A4-A9 | A9 占 10%，其余均分 |
| 走廊层 BOSS | A9 + C14（判决，限剧情解锁） | AI 按剧情阶段判定，不随机 |

> AI 判定输出约束：只能从本表池子里挑**一个**技能名，且必须是第 2 节总表里存在的名字；拿到后写进参数卡 `skills`（形如 `"湮蚀爆发（lv2）"`），插件会自动拆名并查 `skillMeta` 拿数值。

---

## 7. 参数卡写法示例

```json
{
  "skills": [
    "湮源之力（lv1，失控）",
    "暗核共鸣（lv1）",
    "夜采直觉（lv1）"
  ],
  "skillMeta": {
    "湮源之力": { "power": 45, "cost": 12, "cd": 40, "type": "atk", "range": "melee", "lv": 1, "buff_type": "", "effects_type": "dark" },
    "暗核共鸣": { "power": 0, "cost": 10, "cd": 120, "type": "buff", "range": "melee", "lv": 1, "buff_type": "Attack", "effects_type": "buff_dmg", "perm_Attack": 2 },
    "夜采直觉": { "power": 0, "cost": 6, "cd": 60, "type": "buff", "range": "melee", "lv": 1, "buff_type": "Accelerate", "effects_type": "" }
  }
}
```

### 三条硬约束

1. `skillMeta` 的 key 必须是**去括号、去 lv 注记后的纯名**（`cleanSkillName` 会剥 `（...）` 里的所有内容），否则对不上。
2. 技能名 **≤12 字**，超了 `buildSkills` 会静默截断成两截。
3. 参数卡里同名出现两次 → 插件自动加数字后缀（`湮源之力2`），不要靠这个做「同一技能分 lv」，升级只改 `lv` 与 `skillMeta`。
