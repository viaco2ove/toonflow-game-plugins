# 赦夜人冥夜走廊-第二季 · 物品参考列表

> 用途：① 写地图事件脚本时给 NPC/玩家/掉落/商城挂载物品；② 给「暗核吸收 / 野怪掉落 / 商城」提供**可抽取的物品池**（见 `野怪击杀奖励.事件.md`）。
> 每个物品的 JSON 都是**插件原生字段**，可直接当 `itemMeta["<展示名>"]` 的值使用；展示名同时出现在参数卡 `items` 自由文本里。

---

## 1. 字段规范（插件真源：`entry.ts` `BagItem` / `ItemMeta` / `guessKind` / `defaultHeal` / `inferItemType`）

物品在插件里有**两份数据**，必须同时给对：

1. **参数卡 `items` 字符串**（自由文本，如 `"回气草药×3（野外采集）"`）—— 提供 `name / count / kind / rarity / heal / price / desc`（`parseItemRaw` 解析）。
2. **`itemMeta["<展示名>"]` 结构化对象**（`ItemMeta` 接口）—— 提供 `power / cost / cd / type / range / lv / buff_type / durability / attribute_type / attribute_value / effects_type / quantity / description`。

> ⚠️ **`heal` 是派生值，不在 `ItemMeta` 里**：它由 `defaultHeal(name, kind)` 按「名 + kind」推断（见下表）。想改治疗量，**只能让物品名命中 `defaultHeal` 关键字**（急救/回气/干粮/…），或靠 `bagMeta` 覆盖。下面 A 组物品名都按此设计，确保写出来就是文档里的数值。

### 1.1 `BagItem` 运行时字段（来自 `items` 字符串，可省则由推断兜底）

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| `name` | string | ✅ | 物品名。**最长 20 字**（`cleanName` 截到 20），否则被截断 |
| `count` / `quantity` | number | ✅ | 数量（两个字段等价，运行时取 `count`） |
| `kind` | string | ✅ | `consumable` / `material` / `equipment` / `skill_book` / `quest`（`KIND_LIST`）；不写则由 `guessKind` 按名推断 |
| `rarity` | string | ✅ | `common` / `fine` / `rare` / `epic` / `legend`（`RARITY_LIST`）；不写默认 `common` |
| `heal` | number | ⬜ | 治疗量，**派生**（见 `defaultHeal` 表），不写在 JSON 里 |
| `price` | number | ⬜ | 售价，默认 0 |
| `desc` | string | ⬜ | 描述注记（参数卡里的「（…）」自由文本，会原样保留进 `ItemMeta.description`） |
| `power` `cost` `cd` `cdLeft` `type` `range` `lv` `buff_type` `durability` `durabilityLeft` `attribute_type` `attribute_value` `effects_type` | — | ⬜ | 这些战斗/属性字段**不靠字符串给**，走 `itemMeta`（见 1.2） |

### 1.2 `ItemMeta` 持久化字段（你直接 author 的对象，存 `t_plugin_session_data.itemMeta["<名>"]`）

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| `power` | number | ✅ | 威力。`type=atk`=伤害值；其余通常 0 |
| `cost` | number | ✅ | MP 消耗（当前版本 HUD 释放不扣蓝，仅作占位/未来 AI 托管） |
| `cd` | number | ✅ | 冷却，**单位 tick**（1 tick = 100ms，`TICK_MS=100`）。`cd=40` → 4 秒 |
| `type` | `"atk"\|"heal"\|"buff"\|"attribute"` | ✅ | 使用分支：heal→回血；buff→护盾特效；atk→造成伤害；attribute→被动属性（不消耗） |
| `range` | `"melee"\|"ranged"` | ✅ | 仅 `type=atk` 生效：`melee`=弧形斩波，`ranged`=火球轨迹 |
| `lv` | number | ✅ | 等级，配置里通常写 `1` |
| `buff_type` | string | ✅ | 仅 `type=buff` 有意义。取值见 `BUFF_TYPES`（`Defense`/`Attack`/`Sustained_Damage`/`Stunning`/`Invincible`/`Accelerate`） |
| `durability` | number | ✅ | **耐久三档**（见 1.4）。`-1`=永久，`0`=一次性，`>0`=有限耐久 |
| `durabilityLeft` | number | ✅ | 运行时剩余耐久，配置里恒写与 `durability` 相同 |
| `attribute_type` | string | ✅ | 仅 `type=attribute` 有意义。取值见 `ITEM_ATTR_TYPES`（`Defense`/`Attack`/`Life`/`Blue`） |
| `attribute_value` | number | ✅ | 被动属性数值（放背包即累加，见 `bagAttributeBonus`） |
| `quantity` | number | ✅ | 数量（与参数卡 `count` 对齐） |
| `description` | string | ✅ | 描述（保留参数卡原注记全文） |
| `effects_type` | string | ⬜ | 属性特效（决定颜色 + 26×26 图标，同技能 `effects_type` 表） |

### 1.3 `guessKind` / `defaultHeal` / `inferItemType` 推断规则（不写 `kind` / 不写 `itemMeta` 时自动套用）

**`guessKind(name)`：**
- `技能|秘籍|心得|卷轴|心法|功法` → `skill_book`
- `剑|刀|枪|弓|甲|盾|护符|戒|铠|斧|杖|靴` → `equipment`
- `丹|散|药|水|包|粮|汤|肉|鱼|果|酒|茶|露` → `consumable`
- 其余 → `material`

**`defaultHeal(name, kind)`**（仅 `consumable` 有值，其余 0）：

| 名含关键字 | heal |
|-----------|------|
| `急救|大补|灵药|仙丹|回天` | 60 |
| `回气|伤药|灵泉|清心|愈合` | 30 |
| `干粮|粮|肉|果|汤|鱼` | 14 |
| 其他 consumable | 20 |

**`inferItemType(name, kind)`**（无 `itemMeta.type` 时）：
- `kind=skill_book` → `{buff, melee}`
- `kind=equipment` 或 名含 `刀|剑|枪|弓|弩|斧|杖|匕|爪|锤` → `{atk, 弓|弩|杖→ranged 否则 melee}`
- 名含 `力量|攻击|加攻` → `{attribute, melee}`
- 其余 → `{heal, melee}`

> 小技巧：想让一个 `consumable`（如「力量酒」）走 `attribute` 分支，必须**显式在 `itemMeta` 里写 `type:"attribute"`**——光靠名推断会被 `kind=consumable` 挡成 `heal`。

### 1.4 耐久三档（`useBagItem` 消耗逻辑）

| `durability` | 语义 | 使用后行为 |
|--------------|------|-----------|
| `< 0`（通常 `-1`） | **永久** | 不扣数量、不扣耐久，可反复用（武器/被动属性品用这个） |
| `= 0` | **一次性** | 每次使用 `count - 1`，用光移除 |
| `> 0` | **有限耐久** | 同一件 `durabilityLeft` 递减，用尽才 `count - 1` 换新并重置耐久 |

### 1.5 核类物品（暗核吸收链路）

- 命中 `CORE_ITEM_RE = /暗核|湮核|源核|核晶|兽核/`，**或** `itemMeta[名].grant==="skill"` / `.core===true` → 视为核品。
- 使用核品：`gainPlayerExp(CORE_USE_EXP=40)`；并以 `CORE_SKILL_P=0.5` 概率置 `_pendingCoreGrant`，由宿主异步问 AI 判定「获得什么技能」（见 `技能参考.list.md` §6 池子）。
- 核品**不需要**写完整 `itemMeta`——名字命中正则即可触发；但建议仍给 `durability:0` 让它被消耗。

## 6. 抽取池 / 掉落参考（供 AI 判定「给什么物品」）

| 来源 | 可抽池 | 权重建议 |
|------|--------|---------|
| 普通野怪尸体宝箱 | A1,A3,A5,B1 | 均分 |
| 暗核池（畸口普通） | A2,A4,B2,B3,B4,C1,C6 | A 治疗 30% / B 装备 40% / C 核+结晶 30% |
| 畸口精英 | B2,B3,B4,C2,C6 | 装备 40% / 核 40% / 结晶 20% |
| 野兽 | C4,A3 | 兽核优先 |
| 走廊层 BOSS | C3 + 任意 A/B（按剧情） | AI 按剧情阶段判定，不纯随机 |
| 任务奖励 | C5 | 固定，不走随机 |

> AI 判定输出约束：只能从本表池子里挑**一个**物品名，且必须是第 2 节总表里存在的名字；拿到后写进参数卡 `items`（形如 `"暗核×1"`），插件会自动解析 + 查 `itemMeta` 拿数值。

### 三条硬约束

1. **`itemMeta` 的 key 必须 = 参数卡 `items` 里的「展示名」**（`cleanName` 会剥 `×N`、`（…）`、货币尾注、限长 20 字），否则对不上、`mergeBag` 套不到战斗参数。
2. **物品名 ≤ 20 字**，超了 `cleanName` 会静默截断；治疗量只能靠名命中 `defaultHeal` 关键字（急救/回气/干粮/…），`ItemMeta` 里没有 `heal` 字段。
3. **`type=attribute` 的物品放进背包即被动加成**（按 `attribute_type`+`attribute_value` 累加），想要它常驻就把 `durability` 设 `-1`；核品名字命中 `暗核|湮核|源核|核晶|兽核` 即触发吸收链路，不必写完整 `itemMeta`。
