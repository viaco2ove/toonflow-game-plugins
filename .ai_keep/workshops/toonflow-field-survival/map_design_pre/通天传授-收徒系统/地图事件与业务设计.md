# 通天传授-收徒系统 · 地图事件与业务设计

> 路径：`workshops/toonflow-field-survival/map_design_pre/通天传授-收徒系统/`
> 状态：设计稿 v0.1（2026-10-10）
> 上游依据：`.cache/story/通天传授-收徒系统.md`（chapter 1 · 拜师大罗宗 · 6 phase）
> 下游消费：地图编辑器 (src/tools/.../map-editor) + 插件运行时 (plugins/toonflow-field-survival)

---

## 1. 设计目标

把 chapter 1 的 6 个 phase 全部**数据化**，做到：

1. **零代码改 game**：所有剧情/教学/数值推进都通过 JSON + TS 脚本实现
2. **flag 唯一来源**：玩家卡（`t_plugin_session_data`），story.json 不存任何 flag
3. **AI 可写**：Claude Code 写 JSON / TS 经过 `validate_events.mjs` 校验后即可上线
4. **跨剧情可复用**：别的地图集（赦夜人冥夜走廊-第二季）能直接复制 events/ 框架
5. **编辑器零负担**：地图编辑器只显示「事件 ID 字段」，不调试不连线

## 6. 核心设计决策

| 决策 | 选项 | **本设计** | 理由 |
|------|------|-----------|------|
| 存储位置 | story.json / t_plugin_session_data / 单独存档 | **t_plugin_session_data（玩家卡）** | 玩家卡即唯一来源；多玩家/多剧情不串 |
| 引擎类型 | 白名单 JSON / 全 TS / 混合 | **混合（80% JSON + 20% TS）** | 简单走 JSON（AI 好写、校验方便）；复杂（教学/剧情/动态战斗）走 TS |
| 校验 | 人工 / 运行时 / 写时 | **写时静态校验** | `validate_events.mjs` 跑：ctx API 导出表 + 地图 uid 表 + flag 命名空间 |
| 编辑器 | 不改 / 显示 ID / 可视化 | **只显示 ID** | 不做调试不做连线 |
| 触发器挂点 | 散落 / 中央 / 每图 | **每图一份 maps/<name>.events.json** | 删图删事件，命名空间清晰 |
| 跨图共享 | 复制 / shared/ | **shared/** | `_ctx.ts` 单文件类型表，TS 编译期检查 |
| 自定义动作 | 加引擎枚举 / 钩子注册 | **钩子注册** | `registerAction(name, fn)`，JSON 引用 name |
| 触发器类型 | 引擎枚举 | **核心白名单 + registerTrigger 扩展** | 高频 trigger（area_enter/interact/portal/step_on/turn_count）写死；冷门 trigger（time_of_day/inventory_full 等）通过 registerTrigger 动态加 |

## 7. 白名单 trigger / condition / action

> 完整 enum 表由 `events/shared/_ctx.ts` 导出。校验脚本据此生成 JSON schema。

### 7.1 Trigger（触发器）

| type | 必填参数 | 触发时机 |
|------|---------|---------|
| `area_enter` | `zone` | 玩家进入指定 zone |
| `interact` | `uid` | 玩家与对象交互（E 键） |
| `step_on` | `tile` | 玩家踩到指定 tile（x,y） |
| `portal` | `uid` | 玩家与 portal 互动 |
| `enter_map` | （无） | 玩家进入本图 |
| `turn_count` | `>=` | 玩家本地图内回合数达到阈值 |
| `kill_count` | `>=` | 玩家本地图内击杀数达到阈值 |
| `flag_set` | `key` | 任意 flag 被设置（监听） |
| `time_of_day` | `hour` | 游戏内时间到指定小时（自定义动作） |
| `inventory_full` | `>=` | 背包格子满（自定义动作） |

### 7.2 Condition（条件）

| type | 必填参数 | 含义 |
|------|---------|------|
| `flag_check` | `key, value` | flag === value（支持 `==`/`!=`/`>`等） |
| `flag_exists` | `key` | flag 已设置 |
| `phase_active` | `phaseId` | 当前 phase 是指定 |
| `phase_done` | `phaseId` | 指定 phase 已完成 |
| `level_reached` | `>=` | 玩家等级达标 |
| `has_item` | `itemId, count` | 背包里有指定物品 |
| `npc_alive` | `uid` | NPC 还活着 |
| `random` | `p` | 概率条件（0-1） |

### 7.3 Action（动作）

| type | 必填参数 | 含义 |
|------|---------|------|
| `set_flag` | `key, value` | 设置玩家 flag |
| `del_flag` | `key` | 删除 flag |
| `teleport_player` | `map, x, y` | 传送玩家到指定坐标 |
| `spawn` | `mobType, x, y, count` | 生成怪物 |
| `despawn` | `uid` | 移除对象 |
| `move_npc` | `uid, to_zone/x/y, face` | 移动 NPC |
| `set_label` | `uid, text` | 改 NPC 头顶名 |
| `set_sprite` | `uid, spriteId` | 改 NPC sprite |
| `play_sound` | `name` | 播放音效 |
| `play_bgm` | `name, loop` | 切换 BGM |
| `show_toast` | `text, color` | 右下角飘字 |
| `show_subtitle` | `text, duration` | 中部字幕 |
| `show_dialogue` | `uid, text, options` | 弹出对话选项 |
| `give_item` | `itemId, count` | 给物品 |
| `take_item` | `itemId, count` | 收物品 |
| `run_script` | `script, args` | 调用 TS 脚本（fallback） |
| `wait` | `ms` | 等待（动画/转场用） |
| `register_action` | `name, args` | 调用 registerAction 注册的自定义动作 |

## 8. ctx API（游戏引擎导出 TS 类型）

```ts
// events/shared/_ctx.ts —— 单文件类型表，TS 编译期检查 + 校验脚本扫描

export interface Ctx {
  player: {
    id: string
    name: string
    level: number
    sect: string
    title: string
    hp: number
    mp: number
    atk: number
    exp: number
  }
  save: {
    getFlag<T = any>(key: string): Promise<T | null>
    setFlag(key: string, value: any): Promise<void>
    addFlag(key: string, delta: any): Promise<void>
    delFlag(key: string): Promise<void>
    onFlagChange(key: string, cb: (newV: any, oldV: any) => void): () => void
  }
  npc: {
    byUid(uid: string): Promise<NpcHandle | null>
    setLabel(uid: string, label: string): Promise<void>
    setSprite(uid: string, spriteId: number): Promise<void>
    move(uid: string, to: { x: number; y: number } | string): Promise<void>
    wander(uid: string, range?: number): () => void
    setCamp(uid: string, camp: 'hostile' | 'neutral' | 'friendly'): Promise<void>
  }
  ui: {
    showToast(text: string, color?: 'gold' | 'red' | 'white' | 'blue'): Promise<void>
    showSubtitle(text: string, durationMs?: number): Promise<void>
    showDialogue(uid: string, text: string, options?: string[]): Promise<number>
    setHudFlag(icon: string, label: string): Promise<void>
    removeHudFlag(label: string): Promise<void>
  }
  level: {
    switchTo(mapFile: string, x: number, y: number): Promise<void>
    unlock(mapFile: string): Promise<void>
    lock(mapFile: string): Promise<void>
    spawn(mobType: string, x: number, y: number, count?: number): Promise<void>
    despawn(uidOrPredicate: string | ((e: Entity) => boolean)): Promise<void>
  }
  audio: {
    play(name: string): Promise<void>
    bgm(name: string, loop?: boolean): void
  }
  phase: {
    current(): string
    unlock(phaseId: string): Promise<void>
    setOnFire(phaseId: string, fn: (ctx: Ctx) => Promise<void>): void
    isDone(phaseId: string): Promise<boolean>
  }
  registerAction(name: string, fn: (args: any, ctx: Ctx) => Promise<void>): void
  registerTrigger(name: string, def: { params: string[]; fire: (state: any, args: any) => boolean }): void
  askLLM(prompt: string, opts?: { history?: any[]; persona?: string }): Promise<string>
  log: { info, warn, error, event }: LogFacade
}

export interface NpcHandle {
  uid: string
  label: string
  hp: number
  camp: 'hostile' | 'neutral' | 'friendly'
  setLabel(text: string): Promise<void>
  setSprite(spriteId: number): Promise<void>
  onDeath(cb: () => void): () => void
}
```

## 11. 引擎侧改造（entry.ts / mockHost.ts）

```ts
// plugins/toonflow-field-survival/entry.ts
import { loadEvents } from '../../../workshops/.../events'

async function setupEvents(mapName: string, ctx: Ctx) {
  const events = await loadEvents(mapName, ctx)  // 加载 JSON + 绑定 trigger
  registerExtensions(ctx)  // 注册自定义动作
  for (const ev of events) {
    engine.on(ev.trigger, async () => {
      if (!checkConditions(ev.conditions, ctx)) return
      for (const action of ev.actions) {
        if (action.type === 'run_script') {
          await runScript(action.script, action.args, ctx)
        } else if (action.type === 'register_action') {
          await ctx.dispatch(action.name, action.args)  // 走 registerAction 表
        } else {
          await builtinActions[action.type](action, ctx)
        }
      }
    })
  }
}
```

**dev-host / mockHost** 同样需要在 `loadMapConfig` 之后调用 `setupEvents(mapName, ctx)`。

| TS 脚本 crash 导致游戏崩 | 引擎侧 try/catch + 写脚本 validator 走 schema 校验 + ctx API 导出表 |
| AI 写出循环死循环 | validator 静态检查（`for(;;)` / `while(true)`）+ 引擎侧 1s timeout |
| flag 命名漂移（typo） | validator 启发式：grep story.md flag 命名空间 + 同名相似检查 |
| 自定义动作 hook 冲突 | registerAction name 加命名空间：`sect_join/ceremony_sect_join` |
| 事件规模爆炸 | 写时拆分（per map），运行时不交叉 |
| 跨剧情复用冲突 | 复制到 map_design_pre/<story>/ 整份即可，flag 命名按剧情区分 |
