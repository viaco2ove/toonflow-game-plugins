# 野外生存 (Field Survival)

> 野外生存 ARPG 小游戏插件 · Toonflow Plugin v1.0.0

## 快速开始

1. 将本插件目录打包为 `.tpg`（zip 格式）
2. 在 Toonflow 管理界面 → 插件管理 → 上传安装
3. 在聊天界面输入 `#野外生存` 或点击侧边栏按钮

## 插件结构

```
toonflow-field-survival/
├── manifest.json          # 插件元数据
├── entry.js              # 前端入口（选择面板 + 事件总线）
├── entry.py              # 后端入口（奖励计算/发放）
├── ui/
│   └── game.html         # 游戏主界面（Canvas 2.5D ARPG）
├── locales/
│   └── zh-CN.json        # 中文本地化
└── READE.md             # 本文档
```

## 玩法

### 阶段一：角色选择
- **参战角色**：进入野外的我方角色（至少选 1 个）
- **观战角色**：旁观角色（不参战）
- **敌对角色**：敌方怪物（至少选 1 个）
- **难度**：简单 / 普通 / 困难

### 阶段二：ARPG 战斗
全屏游戏界面，支持：

| 操作 | 键盘 | 触摸屏 |
|------|------|--------|
| 移动 | WASD / 方向键 | 虚拟摇杆 |
| 普通攻击 | 空格 | 自动（靠近敌人时） |
| 技能 1-4 | 数字键 1-4 | 技能按钮 |
| 技能翻页 | Q/E | ◀ ▶ 按钮 |
| 使用物品 | - | 物品按钮 |
| 退出 | ESC / 退出按钮 | 退出按钮 |

### 阶段三：奖励结算
- 击杀怪物获得经验、金币、物品
- 经验累积可升级（属性提升）
- 所有奖励写入角色参数卡

## 权限说明

| 权限 | 用途 |
|------|------|
| `ui` | 弹出选择面板、游戏界面 |
| `game_state` | 读写角色参数卡、触发奖励事件 |
| `ai_generate` | AI 辅助生成战斗描述 |
| `assets` | 加载游戏资源 |

## 后端 API（entry.py）

由 `MiniGameAgent` 调用，支持以下 action：

| action | 说明 |
|--------|------|
| `init` | 初始化游戏，生成第一波敌人 |
| `spawn_wave` | 生成指定波次敌人 |
| `apply_rewards` | 将奖励写入角色参数卡 |
| `end_game` | 汇总游戏奖励 |
| `get_character_stats` | 获取角色战斗属性 |

## 打包命令

```bash
cd toonflow-game-plugins/plugins/toonflow-field-survival
zip -r ../toonflow-field-survival-1.0.0.tpg .
```

## 游戏设计说明

- **2.5D 俯视角**：Canvas 绘制简易小人模型
- **波次系统**：5 波怪物（简单 3 波，困难 7 波）
- **难度缩放**：敌人属性、奖励倍率随难度变化
- **技能系统**：攻击、防御、火球术、治愈术（带冷却）
- **物品系统**：血瓶（恢复）、宝石（金币）、宝箱
- **掉落机制**：击杀怪物随机掉落经验/金币/物品
- **升级机制**：经验累积自动升级，属性提升
