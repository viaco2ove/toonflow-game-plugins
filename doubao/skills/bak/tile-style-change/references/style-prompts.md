# 现代都市风格 Prompt 参考

按 tile category 分类，每类对应一段 image_edit prompt。

## 通用约束（每组都加）

```
保持像素画美术风格和 32px tile 尺寸感，不要变成写实照片风。
所有 tile 的位置、网格、排列方式完全不变，只改内容风格。
输出尺寸和输入图完全一致。
```

## 地形类

### terrain_grass（草地）
```
把这组草地 tiles 改成现代城市草坪：修剪整齐的深绿色短草，带少量深浅变化，边缘自然过渡。保持像素风格。
```

### terrain_ground / terrain_other（泥土地面）
```
把这组地面 tiles 改成现代城市路面：浅灰色水泥人行道砖，带砖缝纹理，部分带修补痕迹。保持像素风格。
```

### terrain_water（水面）
```
把这组水面 tiles 改成现代城市河道：蓝绿色平静水面，带轻微波纹反光，边缘有混凝土堤岸。保持像素风格。
```

### terrain_edge（地形边缘）
```
把这组边缘过渡 tiles 改成现代道路边缘：人行道和马路的交界处，有路缘石和轻微色差过渡。保持像素风格。
```

```
把这组结构边缘 tiles 改成现代建筑边缘：楼宇转角、屋顶檐口、围墙端头。保持像素风格。
```
