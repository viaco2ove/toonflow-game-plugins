对比 `compiled_tileset_32x32.original.png`，**只有 5292 和 5300 被替换**（标红），另外 14 格还是原始的绿皮造型 —— 看上面那张联络图最左边一格（5292，深色带角）跟其余 15 格完全不是一个画风。游戏里半兽人走动画时会在「新造型↔旧造型」之间跳变。

## 三个数据源的覆盖度不一致（容易踩坑）

| 来源 | 覆盖的格子 |
|---|---|
| `entity_types.json` → ORC.textures | `[5292,5293,5294,5295,5296,5297,5299]` 7 格（**不含 5298**） |
| `assets.ts` → `SPRITE_ANIM.orc` | `{idle:5292, walk:[5292,5300]}` 仅 2 格 |
| `assets.ts` → `MOB_TILES.orc` | `5292` 1 格 |
| 图集里实际占用 | **16 格**（5292–5307 连续） |

另外：
- **5298** 在 ORC 的 textures 里没有，但图集里确实是半兽人造型（红框披风那个）
- 地图 JSON 的 `firstgid = 1`，所以 `gid 5300 → tileId 5299`。`mulberryForest.json` 里实际摆的两个半兽人（id 22 / id 32，level 9/10）用的就是 **tile 5299** + 帧 5307
