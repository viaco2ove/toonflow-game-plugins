# 实体形象
实体形象（spriteTile）指的是实体的皮肤外观。而不是实体头上的图像（头像/avatar）

# 系统-角色-实体形象
可以改变实体的形象。 预选：player_sprites 文件夹的实体形象。 也可以ai 生成。
ai 生成可以选择参考头像和上传多个参考图，加入提示词。 或者只用文字进行生成。
生成的实体形象，可以进行删除和选择为用户或者角色的实体形象。

## 生成方案
把上传/AI 生成的图压成 32×32 像素 → 转成新 tile id 注入 tileset → 给 entity 一个新 entity_type 走 walkTileId 渲染。

# 概念
## 概念:实体形象
中文：**实体形象/2D模型/精灵方块/32×32 像素小人/精灵贴图 **
英文：**Entity Sprite/2D Entity mode/Entity skin**

RPG 等游戏里面的一个对象也就是实体。实体形象就是它的模型或皮肤外观。

## 概念:实体头上的图像
中文：**角色悬浮头像 / 头顶名称标签**
英文：**Portrait Overlay / Nameplate（世界空间 UI World-space UI）/avatar**

### 角色悬浮头像的目的
实体头上的图像在这个ai 聊天的RPG 插件里就是低成本显示一个细节成本直接沿用ai 聊天头像的低成本方案例如webp 动图。
而且头像可以跟地图比例不一样，地图缩小依然可以观察的到。
