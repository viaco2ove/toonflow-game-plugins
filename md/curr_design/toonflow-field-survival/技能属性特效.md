技能属性特效
金木水火土，风雨雷电，光明，黑暗，普攻，持续出血，毒，自身buff 等
ItemSlot和SkillSlot增加effects_type字段。
effects_type为空标识默认的特效。

effects_type 字段设计方案
背景：给 SkillSlot、ItemSlot 增加 effects_type?: string，为空字符串 /undefined 时走原有默认特效逻辑；不为空时，按属性类型替换粒子颜色、选择专属 VFX 粒子、飘字色调，实现金木水火土、风雨雷电、光明黑暗、出血、毒素等属性特效。
一、字段基础定义
TS 类型补充
typescript
运行
// 技能/物品属性特效枚举，effects_type 的合法取值
type EffectType =
  | "" // 默认，沿用原有逻辑
  | "metal"  // 金
  | "wood"   // 木
  | "water"  // 水
  | "fire"   // 火
  | "earth"  // 土
  | "wind"   // 风
  | "thunder"  // 雷（电）
  | "light"  // 光明
  | "dark"   // 黑暗
  | "normal"   // 普通普攻（无元素）
  | "bleed"  // 持续出血
  | "poison";  // 毒素
  | "buff_dmg_bonus_fire"  // buff:附加火伤
  | "buff_dmg_bonus_water"  // buff:附加水伤
  | "buff_dmg_bonus_thunder"  // buff:附加雷伤
  | "buff_dmg_bonus_wind"  // buff:附加风伤
  | "buff_dmg_bonus_earth"  // buff:附加土伤
  | "buff_dmg_bonus_metal"  // buff:附加金伤
  | "buff_dmg_bonus_wood"  // buff:附加木伤
  | "buff_dmg_bonus_light"  // buff:附加光伤
  | "buff_dmg_bonus_dark"  // buff:附加暗伤
  | "buff_dmg"  // buff:附加伤害加强
  | "buff_defense"  // buff:防御加强

interface SkillSlot {
  // ...原有字段
  effects_type?: EffectType;
}

interface ItemSlot {
  // ...原有字段
  effects_type?: EffectType;
}
规则：effects_type 为 undefined / "" → 完全沿用旧逻辑，不改动原有颜色、粒子表现，做到向下兼容，旧数据不需要迁移。
存储：直接存入状态，背包编辑面板可以下拉选择这个枚举值。

设计原则：尽量复用现有的 6 种 VFX kind，不新增 drawXXX 绘制函数，通过覆盖color参数、微调 life、增加附加 spark 粒子、调整半径 / 拖尾，实现元素区分，控制开发成本。
不新增大量渲染函数，保持 Canvas2D 现有架构。
