## 二、验收用例

| # | 步骤 | 期望 |
|---|---|---|
| **A1** | 玩家走进野怪 4m 探测半径 | 野怪头顶出现**红色感叹号**（浮动 + 呼吸） |
| **A2** | 玩家退出 4m | 感叹号消失 |
| **A3** | 玩家用带 `effects_type` 的技能打怪 | 怪头顶：**红色血滴 + 红色圆圈**，圈内是该技能的效果图标；怪位置飘字 `-N` 为**红色** |
| **A4** | 玩家普攻无武器属性的怪 | 圈内为兜底文字「**伤**」；飘字仍为红色 |
| **A5** | 野怪打玩家 | 玩家头顶：**粉色血滴 + 粉色圆圈**（圈内「伤」）；玩家位置飘字 `-N` 为**粉色** |
| **A6** | 玩家放 buff 技能 | 玩家头顶：**绿色血滴 + 绿色圆圈**，圈内为 buff 技能图标；无图标时为「**buff**」 |
| **A7** | 等待 1.5s / buff 到期 | hurt 徽章淡出消失；buff 徽章与 `buffs` 列表同时消失 |
| **A8** | 安装态（getAsset）加载 | 圈内图标正常显示；图标 404 时兜底文字仍在 |
| **A9** | 连续战斗 30s | 徽章不累积（每实体最多 hurt+buff 两枚）；飘字不卡顿；走动不卡顿 |
| **A10** | dev-host 桩模式复测 A1/A3/A5/A6 | 与真机一致（桩与 entry 同步） |
| **A11** | 【R5】放 circle 技能 | 玩家脚下出现**粉红色半透明圆形区域**，半径 4m，1.2s 后淡出 |
| **A12** | 【R5】放 cone 技能 | 玩家**面前**出现**粉红色半透明扇形**（60°），只命中扇形内的敌人 |
| **A13** | 【R5】扇形外有怪 | 放 cone 技能 → **扇形外的怪不掉血**（指示区 = 判定区） |
| **A14** | 【R5】朝向正确性 | 怪在玩家正右侧 → 扇形水平朝右；怪在正下方 → 扇形朝下且随 2.5D 压缩变短 |
| **A15** | 【R5】面板改形状后刷新 | 技能仍是 cone（`skillMeta` 没被覆盖写丢字段） |
| **A16** | 【R5】dev-host 桩复测 A12/A13 | 与真机一致（桩也用 `inAttackRange`） |

## 四、回滚

所有改动集中在 `entry.ts`（S1~S3）与 `vue/src`（S4）两个面，回滚成本低：

- 后端：还原 `entry.ts` → 重新 esbuild → 覆盖安装副本 `entry.js`
- 前端：还原 `vue/src` → `npm run build` → `ui/game.html`
- 注意：`ui/game.html` 与 `entry.js` 都是构建产物，**不要手改**，必须重新构建
