## 一、已实现的特效系统

### 1. VFX 粒子层（Canvas 2D 绘制）

**生命周期管理**
- 存储在 `state.vfx: VfxParticle[]`
- 每 tick `tickVfx()` 统一 `life--`，过滤 `life <= 0`
- 最大 60 条，超出自动截断旧条目
- 后端 `vite.config.ts` 每 tick 发 `life--` 衰减命令，客户端收到后直接用后端数据

**6 种粒子类型**

| kind | 绘制函数 | 表现 | 颜色参数 | 典型触发 |
|------|---------|------|---------|---------|
| `slash_arc` | `drawSlashArc` | 1/4 白弧斩波 + 淡黄拖尾，旋转消失 | 固定白/黄 | 普攻 / 近战技能 |
| `fireball` | `drawFireballPx` | 橙→红弹体 + 3 个拖尾粒子，沿起点→目标飞行 | `p.color` 默认 `#ff8c3a` | 远程技能（`range: "ranged"`） |
| `heal_ring` | `drawHealRing` | 绿/青环向外扩张 + 淡出，双圈 | `p.color` 默认 `#5fe57a` | 治疗技能 |
| `buff_ring` | `drawBuffRing` | 六边形描边 + 慢速旋转 | `p.color` 默认 `#f5c542` | Buff 技能 |
| `explosion` | `drawExplosion` | 3 圈扩散 + 中心径向渐变填充 | `p.color` 默认 `#ff8c3a` | 爆炸效果 |
| `spark` | `drawSpark` | 单个小亮点 + 阴影辉光 | `p.color` 默认 `#fff` | 火花/闪烁 |

**VfxParticle 接口** (`types.ts`)
```typescript
interface VfxParticle {
  id: string;
  kind: "slash_arc" | "fireball" | "heal_ring" | "buff_ring" | "explosion" | "spark";
  x: number;       // 世界米坐标（由 wx2px 转换到屏幕像素）
  y: number;
  targetX?: number;
  targetY?: number;
  targetEntityId?: string;
  entityId?: string;  // 绑定实体，自动跟随移动
  life: number;        // 剩余帧数
  total: number;       // 初始帧数（用于算 progress）
  color?: string;
  angle?: number;      // ★ 弧形斩波朝向（度数，0=右 90=下 180=左 270=上）
}
```

**跟随机制**：如果粒子有 `entityId`，每帧查找对应实体的当前 x/y 作为渲染基准，解决玩家移动后特效漂移的问题。

**推送入口**
- `pushVfx(p)` — 通用推送
- `pushAttackVfx(from, to, ranged, effects_type?)` — 自动选 fireball（远程）/ slash_arc（近战），按 `effects_type` 替换主色调

### 2. 飘字层（Floaters）

**存储**：`state.floaters[]`

**Floater 结构**
```typescript
interface Floater {
  id: string;
  text: string;
  x: number; y: number;  // 世界米坐标
  life: number;          // 剩余帧
  kind: "damage" | "heal" | "buff" | "debuff" | "text";
  color: string;         // 实际渲染颜色
}
```

**触发场景**
- 玩家受伤：`"-" + damage`，红色 `#ff5a5a`
- 玩家治疗：`"+" + heal`，绿色
- 敌人受伤：同上，在敌人位置显示
- 技能使用：飘技能名称

**渲染**：屏幕像素 alpha 按 `life/12` 衰减，y 坐标随 life 向上漂移。

### 3. 点击反馈层

**A* 路径虚线**：从玩家到目标点的黄虚线，确认寻路是否绕墙。

**点击涟漪**：双环扩散 + 中心实心点
- 绿 `rgb(140, 224, 122)` = 可达
- 红 `rgb(255, 107, 107)` = 不可达（加 X 叉）
- 共 36 帧（约 0.6 秒）

**目标标记**：移动中持续显示脉冲圆环 + 十字，颜色与可达性一致。

### 4. 实体动作特效

**受击闪烁**（`hitFlashMs`）
- 怪物被打时触发，持续 ~200ms
- 实体半透红叠加

**动作小跳**（`actionBobMs`）
- 释放技能 / 普攻 / 使用物品时触发
- `y 偏移: 0 → -4 → 0`（sin 弧线，300ms）
- 野怪发动攻击时也跳

**击退速度**（`knockbackVx/Vy`）
- 受击时沿攻击方向施加 0.4 米/tick 初速
- 每 tick × 0.75 衰减，约 6 tick 归零
- 复用 mockHost tick 循环（不依赖 App.vue ms 系统）

**死亡淡出**（`deathMs`）
- 击杀时设为 400ms
- 渲染时 `globalAlpha = deathMs/400`，每 tick -100ms 衰减
- 归零后由宿主移除实体

### 5. 技能栏技能特效

**技能数据结构**（`SkillSlot`）
```typescript
interface SkillSlot {
  name: string;
  power: number;     // 正=伤害，负=治疗量
  cost: number;      // MP 消耗
  cd: number;        // 冷却帧数
  cdLeft: number;    // 当前剩余冷却
  type: "atk" | "heal" | "buff";
  range: "melee" | "ranged";  // 影响 VFX 类型
  effects_type?: EffectType;  // ★ 属性特效（金木水火土等）
}
```

**内置技能**（`buildInitialState`）
- 冲斩（近战，cd 30，effects_type=metal）
- 火球（远程，cd 60，effects_type=fire）
- 治疗（近战，cd 90，effects_type=wood）
- 护盾（近战，cd 120，effects_type=earth）

### 6. 物品系统特效

物品与技能共用同一套 VFX 映射，映射规则：

| 物品 type | 特效行为 |
|-----------|---------|
| `atk` + `range: "melee"` | 弧形斩波 + 角色小跳 + 飘字威力值 |
| `atk` + `range: "ranged"` | 火球弹体 + 角色小跳 + 飘字威力值 |
| `heal` | 治疗环（heal_ring） + 角色小跳 + 飘字治疗量 |
| `buff` | 护盾环（buff_ring） + 角色小跳 + 飘字 Buff 类型名 |
| `attribute` | **无特效**：被动加成，放入背包即生效，使用不消耗 |
| 其他（utility 等） | 角色小跳 + 飘字物品名（通用降级特效） |

**物品数据结构**（`ItemSlot`）
```typescript
interface ItemSlot {
  name: string;
  count: number;
  heal: number;
  mp: number;
  type: "hp" | "mp" | "atk" | "buff" | "utility";
  effects_type?: EffectType;  // ★ 属性特效
  // ... 其他字段
}
```

**背包面板功能**（`BagPanel.vue`）
- 网格显示：图标（颜色按 rarity）+ 名称 + 数量 + 等级标签
- 稀有度颜色：`common` 灰 / `fine` 蓝 / `rare` 紫 / `epic` 橙 / `legend` 金
- 拖拽排序、按名称排序
- 卖出：可指定数量，扣除金币
- 内联编辑：包含 13 个 effects_type 选项

## 二、渲染层次（从底到顶）

```
1. 地形地表（terrain draw）
2. 地形物件（树木、石头等）
3. 实体（玩家、野怪、NPC）+ 击退位移 + 死亡淡出
4. HP/MP 条
5. VFX 粒子层 ← 战斗特效（含震屏偏移）
6. 点击涟漪 + A* 路径 + 目标标记
7. 飘字层（floaters）
```

## 三、问题与局限

| 问题 | 说明 |
|------|------|
| 特效全为纯 Canvas 2D 绘制 | 无骨骼动画 / 序列帧，视觉表现力有限 |

# P1 打击感优化（2026-10-09 已完成）

✅ **已完成 5 项**

| 优化 | 实现位置 | 行为 |
|------|---------|------|
| 震屏（Screen Shake） | `App.vue:shakeFrames/shakeIntensity` + `mockHost.ts:flashEntity` | 受伤时 canvas 随机偏移 ±4px，持续 6 帧（0.1s），3 帧衰减 |
| 顿帧（Hit Stop） | `App.vue:hitStopFrames` + `mockHost.ts:flashEntity` | 命中时跳过 3 帧渲染（~50ms），保持小地图刷新 |
| 击退（Knockback） | `mockHost.ts:knockbackEntity` + `tickKnockback` | 命中时沿攻击方向施加 0.4 米/tick 初速，每 tick ×0.75 衰减，~6 tick 归零 |
| 斩波朝向 | `mockHost.ts:pushAttackVfx` + `App.vue:drawSlashArc` | VfxParticle 加 `angle` 字段，`drawSlashArc` 按度数旋转弧形（刀刃朝外） |
| 敌人死亡淡出 | `mockHost.ts:deathMs=400` + `App.vue:drawEntity/drawMonster` | 击杀后 400ms 内透明度从 1→0 淡出，`deathMs` 每 tick -100ms 归零后移除 |

**实现细节**
- 震屏/顿帧通过 `window.__fsTriggerShake / __fsTriggerHitStop` 跨模块桥接
- 击退在 mockHost tick 循环内衰减，不依赖 App.vue 的 ms 衰减系统
- 死亡淡出同时作用于 `drawEntity`（角色/NPC）和 `drawMonster`（野怪）

## 二、渲染实现（`App.vue`）

- `VfxParticle.icon` 字段：放图标相对路径；`kind` 新增 `icon_burst`
- `spellIconCache`：图标 LRU 缓存（20 张上限），首次未加载完返回 null（光环先出，图标下一帧跟上）
- `drawIconBurst`：同色光环（0.7→1.5 倍扩散）+ 图标 0.7×→1.5× 放大淡出，`imageSmoothingEnabled=false` 保持像素锐利
- 叠加规则：`slash_arc` / `heal_ring` / `buff_ring` 图标叠在施放者位置；`fireball` 图标跟随弹体飞行

## 三、生成端（`entry.ts`）

- effects_type 为空 → `icon: ""` → 不叠图标（向下兼容）
