## 2. 实测记录（31 项 MCP + 关键数值）

- **A 组协议合规**：无 token 401；GET/DELETE 405；缺版本 header 400（UnsupportedProtocolVersionError）；未知版本 400；`Mcp-Method`≠body 400+-32020；`tools/call` 缺 `Mcp-Name` 400；`Mcp-Name`≠params.name 400+-32020；未知方法 404+-32601；非法 JSON 400+-32700；text/plain 415；通知（无 id）202；非法 Origin 403（token 合法也拒）。
- **B 组**：initialize 回显 `2026-07-28`；initialize 不带 header（body 协商）200；未知 body 版本 → 返回服务端最新（协商语义）；tools/list 返回 5 tools（含 inputSchema/description）。
- **C 组**：query_state 返回 phase/tick/kills/金钱/玩家/敌人（按距离排序，含 id）/特效数/最近事件；kill_mob 缺 targetId → -32602；假 id → isError「目标 X 不存在或已死亡（可用 query_state 查看当前存活敌人）」；spawn_entity 图鉴外类型 → isError 并列出可用类型；真实 kill → `普攻 → 荒野游荡者 -78`（与玩家点击同一条权威结算链）；clear_effect all → `已清除全部特效（N 个）`；plugin_events_push → DB `__plugin_events__` 队列 +1；会话不存在 → isError 可读。
- **D 组**：12 只怪并发 kill（4 线程）+ 10Hz 持续 tick → 0 次 5xx、0 次 tick 回退，kills 增量与成功结算数逐一吻合；被 AI 杀掉的怪连续 5 个帧 tick 不复活（共享内存态生效）；击杀后 ≤2 帧 tick 内渐隐启动（玩家可见）。
- **演示时间线（e2e）**：initialize → tools/list → query_state → spawn_entity → kill_mob（`普攻 → -78`）→ clear_effect 全链路走通。

## 3. 测试过程中发现并修复的问题

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | 同 tick 多批 spawn 实体 id 碰撞（DB 里 `ai_enemy_1_58_0` 出现 4 次） | `ai_spawn` 的 id 用 `s.tick_i`，同 tick 两批必然撞车 → kill_mob 按 id 索敌错杀 | id 加随机段（参照 floater/pushVfx 写法） |
| 2 | 压测把玩家围殴致死（phase=over）→ 后续渐隐/写操作全部冻结 | 30 只怪刷在玩家 1m 处，10Hz 围殴 ~1s 团灭；这是**游戏逻辑正确**的表现，是测试设计问题 | 测试改：revive 前置（回满血+敌人 2s 攻击冷却）+ 刷在 3.5m（可 kill 但离攻击范围 ~1.4s 路程） |
| 3 | initialize 带 header 未知版本被 400 | 我自己的 header 校验把 body 协商版本也当 header 版本拦了 | header 层对 initialize 豁免「支持清单」检查（协商语义：返回服务端最新） |
| 4 | kill_mob 假 id 只回「附近没有敌人」 | entry `attack` 的 inRange 空分支早退在 targetId 判定之前 | 空分支里先看 targetId：给「不存在/太远」精确原因 |
| 5 | R4b 回归断言FAIL（期望「附近没有敌人」） | 断言绑定了旧文案；新文案语义更准（目标已死） | 断言改为语义判定（攻击被拒绝、无伤害结算），不绑定单一文案 |


手动连一次：

```bash
curl -s -X POST http://127.0.0.1:60002/plugin/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -H "MCP-Protocol-Version: 2026-07-28" \
  -H "Mcp-Method: tools/list" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

安全边界提醒：`/plugin/mcp` 只允许本机回环访问 + 必须带用户 JWT token + 默认拒绝一切带 Origin 的浏览器请求（`MCP_ALLOWED_ORIGINS` 可放行白名单）。token 泄漏即等于会话操作权泄漏，不要把带 token 的命令贴到共享环境。

## 5. 遗留与二期

- M5（`subscriptions/listen` 变更广播 / keepalive）按 v3 §10 搁置，触发条件：AI 需要 world-change 事件流而非轮询 query_state。
- `O4 快慢锁`的残余竞争窗口（sys_* 慢命令写回 vs 帧 tick，≤2s）维持 v2 §3.4 结论不变，MCP 工具全部走 fast 锁不受影响。
- 多进程部署时内存态需换成共享存储（v3 §5.1 已注明）；当前单进程（本地开发/单机部署）不受影响。
