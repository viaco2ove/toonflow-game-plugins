# 名称:野外生存
# 命令:#野外生存
# 玩法
## 输入或选择"#野外生存"
弹出小游戏面板
面板有：参展角色（多选），观战角色（多选），敌对角色（多选）
开始游戏（按钮）
## 全屏显示"野外生存"游戏界面,有退出按钮。 
### 半透明控制按键：
虚拟方向按键（pc 的键盘方向键也可以控制，鼠标点击空地也能控制移动目标），四个技能（按钮）
技能就是 用户参数卡技能里的前四个。旁边有【切换】按钮 可以切换下一页技能
四个物品格，点击使用或者消耗物品。 旁边有【切换】按钮 可以切换下一页物品

# 角色头像
直接在2.5 d 的”小人“模型上方显示一个适合比例的头像和角色名称。

# 奖励机制
杀怪可以获取经验和物品和金钱，写入用户和角色的角色参数卡里。
打开宝箱可以获取经验和物品和金钱，写入用户和角色的角色参数卡里。
地上的血瓶用户和角色走过去就可以恢复角色生命值。

# 结束机制
主动退出/用户死亡

# agents 设计
## field-survival-map-gener agent
利用故事的信息（动态角色卡，故事动态数据）去生成合适的地图数据和设定。和持续的地图动态数据维护。

# 数据变量
## 故事的动态数据
就是故事的动态角色卡，故事动态等数据
## 系统的配置数据
例如模型接口配置等数据
## 插件数据
就是不太适合保存到故事的动态数据的数据。就独立保存到插件数据里。
插件的运行时数据。
那个插件，那个故事会话，那个用户的数据。
t_plugin_session_data
(id,sessionId,pluginName,pluginId,dataKey,dataValue)

例如生成的地图数据。  

## 读取和设置
后端通过toonflowTsApi  读取和设置这些变量
前端通过toonflowJsApi 调用接口读取和设置这些变量
