## 安卓端崩溃修复：state.entities undefined → find NPE（12:28-12:35）
现象：安卓 Ubuntu 服务 (10.10.2.195:8088/60002) 加载 ui/game.html 立即崩：
  TypeError: Cannot read properties of undefined (reading 'find')
  at state.value?.entities.find(...)
两层根因：
1. `state.value?.entities.find()` 的 ?. 只保护 state.value 为 null；
   entities 字段为 undefined 时 ?. 不生效仍抛 NPE（安卓状态下发早于 entities 就绪）
2. entry.ts handle_action 只按 state.version===2|3|4 判断是否复用旧 state，
   旧存档 version 对得上但缺数组字段 → 残缺 state 被当完整 state 用

修复：
- App.vue 20 处 → (state.value?.entities ?? []).find（含 4 个响应式 getter）
- App.vue:2785 s?.entities.find 同理
- entry.ts handle_action 入口补齐 entities/roles/items/skills/spriteGallery

## bsk 实测 8088：小游戏开局超时的真根因 = entry.js 没 bundle（commit 52ca722）

完整链路（桌面 Chrome 连 10.10.2.195 实测，安卓同源复现）：
1. 8088 nginx→SPA 正常，SPA baseUrl(localStorage)=60002，iframe getAsset 正常，

   返回 code=0 phase=select 37 字段；MD5 6017e45e 已同步 run-db
