### v2 完整版（16:30-17:00）—— 补齐补充.md 的全部功能
**根因**：v1 用 confirm 二选一凑合，是因为引擎只有 `ctx.ui.confirm()`。v2 先补引擎能力再实现完整功能。

**引擎新增五项能力**（原本只有 confirm）：
- `ctx.ui.select(opts)` → App.vue `evSelectOpen` + `.ev-select__*` 样式（多选面板）

**新增 7 个后端 cmd**：`sys_agent_run` / `sys_bag_list` / `sys_bag_remove` / `sys_forge_create`（改）/ `sys_alchemy_create`（改）/ `sys_item_upgrade` / `sys_item_dissolve`

## 假人事件实现（17:45-18:00）
- **核心机制**：假人 `camp=neutral` 原本走「NPC 装饰物」分支（没 hp 不能被打）。
  地图加 `training_dummy=true` → mapConfig `isTrainingDummy()` 特批进 mobs →
  App.vue 按 `camp=neutral → side=neutral` 生成实体（有血条、不主动攻击、可被打）
- **点击攻击扩展**：App.vue 和 entry.ts case "attack" 的索敌从 `side==="enemy"` 扩为「enemy 或 trainingDummy」
- **damage() 假人分支**：摧毁假人不走 enemy 的经验/金钱/掉落链；实战模式写 flag
  `dummy_destroyed_<id>`（走 `setPlayerFlag`→`player_flags` 表，与事件引擎 flagCache 同源）
- **`sys_dummy_reward` cmd**：事件脚本轮询到 flag 后发经验 `10 + lv×6`
- **`lastPluginContext`/ctxRef()**：damage() 是同步函数拿不到 ctx → 模块级引用 handle_action 的 context
- **假人4 auto 等级**：地图 level=0 → App.vue 按 `玩家等级+5` 生成（每次进图重算）
- **E70_training_dummy.ts**：模式菜单（站桩/模拟实战）；站桩挂 1s 回血计时器（假人 5%/s，
  离开 4m 结束复位）；实战轮询 destroyed flag 发经验（离开 6m 视为逃跑复位）
- **events.json**：`E70_dummy_1~4`（uid=251~254 共用脚本）
- **测试**：`test-training-dummy.mjs` **55 断言全过**；entry.js 258.4kb / game.html 505.13kB 构建通过
