## [suc] ★ 技能冷却「不像秒」+ 技能特效不消失 根因修复（15:28）
- 用户实测（dev-host，赦夜人）：施放技能后技能格倒计时长时间不减少；技能特效不消失。
  截图确认技能栏第 1/2 格为暗色冷却态（名称被遮罩、显示红色角标），物品栏正常。
- **根因**：宿主 tick 频率**不是恒定 10Hz**。前端 `currentSendMs()`（App.vue 6858）
  在玩家 3 秒无输入后把上报降到 `SEND_IDLE_MS = 1000`（1Hz 挂机档，省带宽）；
  而 `entry.ts` step() 里所有计时器都是**每 tick 减 1**（隐含「1 tick = 100ms」）：
    · 技能冷却 `s.skills.forEach(k => k.cdLeft -= 1)`（entry.ts 2388）
    · 飘字 `life -= 1`、特效 `_vfx.filter(v => v.life -= 1)`（entry.ts 2389-2392）
  ⇒ 挂机档 1Hz 下：cd=24（设计 2.4 秒）要 **24 秒**才归零，但 UI 仍按 `/10` 显示「3 秒」
    （App.vue 9307 `Math.ceil(s.cdLeft / 10)`）→ **冷却不像秒**；特效 life=12~30 同样要
    12~30 秒才消失 → **特效不残留**。两者同源、同时出现，与症状完全吻合。
- **修复**（提交 cb4f28a）：改为按**真实经过毫秒数**折算 tick 数递减
  （`cdLeft` 单位仍是 tick 数，UI 口径 `cdLeft/10 = 秒` 不变，无需改前端显示）：
  · `entry.ts`：新增 `TICK_MS_MS = 100` + `tickDeltaMs(s)`（存 `_tickAtMs`，
    钳位 100~10000ms，时钟回拨回退 100ms）；step() 内 `_dec = max(1, round(dtMs/100))`。
  · `vue/src/mockHost.ts`：新增 `mockTickDec()`，standalone 本地预览同口径。
  · `vue/vite.config.ts`：dev-host 降级桩（entry.js 失败时的 fallback）同口径。
- **测试**（此前零覆盖）：新增 `test-host/tick-cooldown.test.mjs`（22 项）——
  此前 `handle_action("tick")` **完全没有测试覆盖**，冷却/特效路径是盲区。
  新测试覆盖：tick 推进 / cdLeft 递减 / vfx 递减 / skill 施放入冷却 /
  UI 显示口径 / **1Hz 挂机档回归（真实 bug 场景）** / cdLeft 不越界。
- 回归：tick-cooldown 22 + 链引擎 70 + 赦夜人 26 + 通天 82 = **200 项全过**。
- 产物：`entry.js` 用 esbuild 官方路径重编（270.3 kB）；`npm run build` 通过
  （103 modules，ui/game.html 592.66 kB）；已同步安装副本
  `toonflow-app-run-db/plugins/1/com.toonflow.minigame-field-survival/`（entry.js + game.html，
  marker `tickDeltaMs` 校验通过）。
