## 实体形象选择器（SpritePicker）：改多选框为下拉框，支持 6 大分类过滤

- **根源**：旧版只有「只看人物」勾选框 → 放两个斧头就需要翻 1100+ 人物贴图找「斧头贴图」→ 效率太低，无工具的防备栏杆。
- **元数据**：后端写 `sprite_catalog.json`（7 类分类 + 条目区间：装备 12 套 × 8 槽 + 零散武器 / 物品 / 告示牌 / 家具），`/sprites` 端点按区间追加 `category` 标签；前端过滤器改下拉框（全部 / 人物 / 武器 / 防具 / 道具 / 告示牌 / 家具 / 其他），默认「人物」。
- **输出**：`sprite_catalog.json`（629 行）在后端 backend/ 目录（全局默认）+ 各地图集可覆盖；后端 `get_sprites` 重写（121 行）；前端 `SpritePicker.vue`（改 5 处，复用既有 UI）、`App.vue` 加 `PICKUP`（可拾取物）放置类型。
- **对照验证**：`.cache/inv_hi_{0,1,2,3,4}.png`（全瓦片拼图）+ `set_layout.png`（11640-11699 一套装备）+ `sign_check.png`（告示牌 / 书架），Anthropic vision 模型识别各格内容来建区间（尤其 4528/4648 的告示牌与店铺招牌）。
- **回归**：`python -c 'import server;r=server.get_sprites("base");print({s["category"] for s in r["sprites"]})'` 出 7 类，斧头（153）与告示牌（4528/4648）归类正确，贴图不会被 `/dawnlike` 截断。装备套（11640 起）也按偏移量精准拆分成剑 / 斧 / 胸甲 / 护腿 / 头盔 / 靴子六部分。构建与语法通过（`vite build + ast.parse`）。
