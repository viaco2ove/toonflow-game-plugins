## 基本参数

| 项 | 值 |
|---|---|
| 图集尺寸 | 3840 x 3488 px |
| 排列 | 120 列 x 109 行，32px/格，margin=0，spacing=0 |
| tilecount | 13080（引擎上限，**新瓦片 id 必须 < 13080**） |

| tile index → 像素 | x = (id % 120) * 32, y = (id // 120) * 32 |

## 延城一中主教学楼的真实结构

```
y= 7   ######  地板+横向构件
y= 8   ########
y= 9   FWWWWWWWWWWWWW   ← 有门有家具的真室内（W=木地板）
y=10   FWWWWWWWWWWWWW
y=11   F?WWWW?WWWW?WW
y=12   FWWWWWWWWWWWWW
y=13   FWWWWWWWWWWWWW   ← L2 是实心屋顶(R)，正好压在上面
y=14   FWWWWWWWWWWWWW   ← 拆掉这 3 行屋顶，下面才是教室
y=15   FWWWWWWWWWWWWW
y=16   ?#W########W##
```
**拆 y=13~15 的屋顶 → 露出 y=9~12 的房间**。教室区域 = x[7..18] y[9..15]。

## 纹理均匀度（uniform）— 区分「路面」与「道具」的关键判据

`avg_color` 是整格平均色，**混合素材会被误判**（按灰色筛会命中台灯、剑、书架、角色）。
真正的判据是**纹理均匀度**：`find_tiles.py --min-uniform 0.62` 会把
家具/角色/杂物全部滤掉，只留路面/墙面这类平坦色块。

| uniform | 典型内容 |
|---|---|
| > 0.75 | 纯色路面、水面、单色墙 |
| 0.55-0.75 | 带纹理的路面、砖墙、地板 |
| 0.35-0.55 | 有细节的家具、门窗、道具 |
| < 0.35 | 角色、杂物、复合图块 |

**用法**：找路面/墙面时 `--min-uniform 0.6` 起步；找具体道具时不要加这个限制。

## 颜色速查（按 avg_color 聚类）

`find_tiles.py --grey/--dark/--warm/--color` 就是基于这个维度筛选的。经验值：

- 深色板墙/黑板底色：luma < 60
- 灰青石砖/水泥：luma 90-160, sat < 0.18
- 木质（橙/棕）：sat 0.3-0.6, 偏暖
- 草地：avg_color ≈ #6daa2c
- 砖红跑道：avg_color ≈ #a0522d 附近，需 warm + 中 luma

## 增删瓦片的规矩

1. **新增**：只落图集内**连续全透明**格，写入前断言该格 alpha 全 0，
   id 必须 < 13080。整格替换用 `alpha_composite` + 不带 mask 的 `paste`。
2. **替换已有格**：先备份整张图集到 `overrides/originals/compiled_tileset_32x32.pre-*.bak.png`。
3. **母版只读**：`resource_library/toonflow-field-survival/base/` 下的是素材母版，
   写操作一律落当前地图集副本，否则当前地图看不到变化。
4. **验证**：写入后校验 tileset 尺寸未变、最大 gid < tilecount、
   关键旧瓦片未被覆盖、新瓦片非空。
