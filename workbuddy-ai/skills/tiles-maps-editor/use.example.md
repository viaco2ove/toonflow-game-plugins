# 瓷砖地图编辑器 技能
## 能力
利用 cognitive-tiles-maps   tile-style-change 等技能对地图进行编辑的能力。   
- 知道每个地图的瓦片样式和布局。
- 改完图要自己验证一下效果，截图观察
- 知道房子、道路、树木等元素的瓦片样式和布局。
- 知道活物等要怎么加到地图和修改
- 知道对应的材质是什么。
- 知道地图编辑器怎么工作（[map-editor](../../../src/tools/toonflow-field-survival/map-editor)）
- 改变街道布局，房子结构布局，墙面材质等

**B 关键贴图替换（中成本）**：木墙→砖墙教学楼立面、土路→水泥路、专门画一块黑板瓦。
