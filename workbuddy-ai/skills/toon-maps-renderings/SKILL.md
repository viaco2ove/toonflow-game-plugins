# Toon Maps Renderings

Toonflow 游戏像素风 RPG 地图的效果图生成与编辑技能。核心目标：在保持现有地图布局骨架和 tile 像素质感的前提下，根据故事主题渲染出氛围更浓、视觉更精美的概念效果图。

## 输入识别

收到 `/toon-maps-renderings` 或地图效果图请求时，先确认三类输入是否齐备：

| 输入 | 典型文件 | 用途 |
|---|---|---|
| 故事设定 | `storyinfo.md` / JSON | 提取地图名称、建筑功能、世界观氛围（黑塔、伪人、超凡等） |
| Tile 素材集 | `compiled_tileset_32x32.png` | 作为风格锚点，保证像素颗粒和材质语言一致 |
| 当前地图截图 | 玩家提供的 PNG | 作为布局骨架参考，保持建筑位置和道路结构 |

缺任意一项时，先向用户索取；不要用纯文本脑补地图布局。

## 核心工作流

### 1. 解析故事与地图要素

从 storyinfo 中提取：
- 地图名称（如"延城一中"）
- 该地图内出现的场景节点（教室、走廊、网球场、天台、黑塔入口等）
- 世界观氛围关键词（悬疑、超凡、黑塔、认知污染、黄昏等）
- 关键建筑的功能定位（教学楼、体育馆、任务大厅、宿舍等）

### 2. 确定渲染方向

默认渲染方向（用户未指定时）：
- **视角**：2D 俯视（top-down），像素艺术风格，32x32 tile 质感
- **氛围**：黄昏暖橙色调 + 远处神秘元素剪影（如黑塔），呼应悬疑超凡故事基调
- **升级点**：建筑细节更丰富、道路材质更精致、树木/喷泉有层次、整体氛围统一

用户指定其他方向时按用户要求执行（白天、夜晚、雨夜、像素纯复古等）。

### 3. 选择生成模式

**从零生成（无现有地图参考）**：
- 使用 `image_gen`，按布局描述 + 风格关键词生成
- 参考故事中的建筑清单规划布局

**基于现有地图升级（有地图截图）**：
- 使用 `image_edit`，以当前地图为第一参考、tile 素材为第二参考
- prompt 中明确 must_keep（布局、像素质感、配色体系）和 must_change（氛围、细节、材质、标签）

### 4. 编译 Prompt 指令

Prompt 结构（按观看顺序写，不堆关键词）：
1. 编辑目标/生成目的
2. 必须保留项（布局骨架、像素质感、tile 风格）
3. 改动区域与具体内容（氛围、材质、建筑标签、道路调整）
4. 视觉语言约束（像素颗粒、色彩职责、光源方向）
5. 禁止项（不要变 3D、不要写实、不要改布局）

详细 Prompt 模板见 [references/prompt-templates.md](references/prompt-templates.md)。

### 5. 交付闭环

每张生成图完成后：
1. 通过 `design-cli design-workspace +create` 写入当前 Canvas Workspace
2. 通过 `present_files` 直接交付给用户
3. 记录版本，便于后续迭代编辑

## 常见调整项

用户在效果图基础上提出局部修改时，使用 `image_edit` 精确调整：

- **道路走向**：重新规划主路/支路布局，保持连通性
- **路面材质**：土路 → 水泥路 → 石板路 → 红砖路
- **建筑外墙材质**：红砖 → 蓝灰砖墙 → 石墙 → 木质
- **建筑名称标签**：在屋顶/门口加像素风中文名称，白字深描边
- **氛围版本**：白天 / 黄昏 / 夜晚 / 雨夜 / 雪天
- **远景元素**：黑塔剪影、城市天际线、山脉、森林

调整时保持其他元素不变，最小改动原则。

## 质量门禁

生成结果必须满足：
- [ ] 像素颗粒感清晰，不变成 3D 渲染或手绘插画
- [ ] 2D 俯视视角，不变成等距(isometric)或斜 45 度
- [ ] 布局结构与参考图一致（升级模式下）
- [ ] 建筑功能与故事设定对应
- [ ] 氛围统一，没有风格冲突的元素
- [ ] 建筑名称文字清晰可读（用户要求时）

不满足时用 `image_edit` 修正，不要重新从零生成。
