## 从零生成：新地图效果图

适用场景：用户只有故事设定和 tile 素材，没有现成地图截图。

```
生成一张竖版 RPG 游戏地图概念效果图，主题是「{地图名称}」，2D 俯视视角，像素艺术风格，32x32 tile 质感。

整体布局：
- {建筑1位置描述，如：左上角是一栋大型主教学楼}
- {建筑2位置描述，如：右侧分布着多栋教学楼}
- {中心区域，如：画面中心是圆形喷泉广场}
- {底部区域，如：底部是运动场/网球场}
- 校园四周环绕着绿色草坪和树木，有围栏边界

建筑清单与功能：
{根据storyinfo列出的建筑，每栋一行：名称 - 功能 - 位置}

视觉风格：
- 像素艺术（Pixel Art）风格，复古 RPG Maker 游戏质感
- 黄昏时分，暖橙色夕阳从侧面照射，建筑投下长长的冷蓝色阴影
- 整体色调温暖但带有一丝神秘和不安
- 远处天际线隐约可见「{世界观元素，如：黑塔}」的剪影
- 红砖/砖墙建筑、绿色草坪、灰色步道

质量要求：像素颗粒清晰，建筑结构合理，布局层次分明，不出现 3D 渲染效果
```

## 基于现有地图升级氛围

适用场景：有当前地图截图，想要升级视觉效果和氛围。

```
在参考图（当前{地图名称}像素地图）基础上，生成升级版效果图。

必须保持：
- 2D 俯视视角（top-down），像素艺术风格，32x32 tile 质感
- 整体布局结构完全不变：每栋建筑的位置、大小、相对关系
- 配色体系（主色板）
- 像素颗粒感和复古 RPG Maker 视觉语言

升级优化：
- 建筑细节更丰富：屋顶瓦片纹理、窗户、门廊、花坛装饰
- 草地纹理更细腻，有深浅变化和小花点缀
- 树木造型更丰富，有树冠层次
- 喷泉/中心景观更精致
- 黄昏氛围：整体色调偏暖橙，建筑投下长长的阴影，天空橙红到深紫渐变
- 远处天际线隐约可见「{世界观元素}」剪影，若隐若现
- 部分阴影区域带一丝诡异的深色/紫黑色调，暗示「{故事元素，如：认知污染}」

禁止：不要改变布局结构，不要变成 3D 渲染，不要丢失像素颗粒感
```

## 氛围变体：白天 / 夜晚 / 雨夜

### 白天版本

```
在参考图基础上调整为白天晴朗氛围：
- 明亮的自然光，色温偏冷白
- 草地鲜绿，建筑色彩饱和度正常
- 阴影短而柔和
- 天空浅蓝色，有少量白云
- 远处「{世界观元素}」清晰可见但不突兀
```

### 夜晚版本

```
在参考图基础上调整为夜晚氛围：
- 整体亮度降低，主色调深蓝紫色
- 建筑窗户透出暖黄色灯光
- 路灯/庭院灯点亮，形成光斑
- 星空可见，远处「{世界观元素}」在夜色中更突出
- 阴影更深，明暗对比更强
```

### 雨夜版本

```
在参考图基础上调整为雨夜氛围：
- 整体色调偏冷蓝灰，阴云密布
- 地面有积水反射，道路湿漉漉的高光
- 建筑表面有水珠质感
- 天空灰暗，远处「{世界观元素}」在雨雾中若隐若现
- 整体氛围压抑、悬疑
```

## 使用提示

- 参考图数量：布局升级类用 2 张参考（当前地图 + tile 素材）；材质参考类加第 3 张材质特写图
- 比例：默认竖版 3:4（1536x2048），横版地图时改为 4:3 或 16:9
- 文字标签：AI 生成的中文文字可能有字形错误，交付后如实告知用户，需要时再修正
- 迭代：每次修改基于上一版结果，保持版本血缘关系
